## 1. 项目概述

## 1.1 项目背景

随着公司业务规模扩大，每年校园招聘成为人才引进的重要渠道。当前招聘流程主要依赖第三方平台（如智联招聘、Boss 直聘）和线下宣讲会，存在以下痛点：

1. 简历分散校招邮箱、各个线下校招专场收集得的纸质简历，效率低下。（这个最主要，主要是希望有一个系统用于收集学生投递的简历，HR能用来发布岗位和处理收集的简历，筛选合适简历用于面试）

2. 缺乏统一的校招品牌展示入口，学生体验不佳

3. 面试通知、进度跟踪依赖人工操作，容易遗漏

4. 无法有效沉淀校招数据，不利于后续招聘策略优化

## 1.2 项目目标

基于开源框架搭建一套自主可控的校园招聘管理系统，实现以下目标：

1. 统一校招入口：建立公司专属的校招门户，学生一站式完成浏览、投递、查进度

2. 提升 HR 效率：集中管理简历、一键筛选、批量操作

3. 流程标准化：从岗位发布到录用的全流程线上化、可追溯

4. 数据可分析：沉淀校招数据，支持多维度统计分析和决策支持

## 1.3 项目范围

本期聚焦于校园招聘核心场景，涵盖三大端：学生端（前台门户）、HR 端（管理后台）、系统管理端。不包含社会招聘、内部推荐等功能，后续可扩展。

## 4. 附录

## 4.1 候选人状态流转

投递 → 待筛选 → 筛选通过 → 待面试 → 面试中 → 面试通过 → 待录用 → 已发 Offer → 已接受/已拒绝 → 已入职

各阶段均可标记为"淘汰"，淘汰时可选择发送感谢信（可以不实现）
