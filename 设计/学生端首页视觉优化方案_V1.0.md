# 学生端首页移动端视觉优化方案 V1.0

> 编制日期：2026-08-10　设计方法：多Agent并行（interface-designer + researcher）+ 品牌视觉规范对齐

---

## 一、核心问题

移动端首页大面积空白、信息密度低、品牌感知弱——深空背景很好但视觉元素松散，用户滑动体验像"跳过一块块空白"。

## 二、设计原则

| 原则 | 说明 |
|------|------|
| **官网视觉一致性** | 配色/字体/玻璃态/渐变语言与官网 `e:\Program\校园招聘简历管理系统\官网` 完全对齐 |
| **移动端优先** | 所有新样式以 ≤767px 为基准断点，桌面端保持现有布局 |
| **不减品牌感** | 缩小的是尺寸和间距，不缩小品牌辨识度 |
| **纯CSS实现** | 零新增npm依赖，零修改script逻辑 |

---

## 三、核心改动（9项）

### 1. Hero区：渐变遮罩 + 统计卡片 + CTA发光

- 新增 `.hero__gradient-mask`：底部向上的深色渐变遮罩（`rgba(10,14,23,0.6)→#0A0E17`），让Hero向内容区柔过渡
- 统计数字：4列flex→2×2 grid + 半透明背景卡片（`rgba(21,37,53,0.5)`）+ 玻璃态(`backdrop-filter:blur(4px)`)
- CTA按钮：常驻发光(`box-shadow: 0 4px 24px rgba(95,184,214,0.25)`)，`:active` 缩放 0.97
- 星空密度降低（背景图 300px），增加品牌色星点比例

### 2. 岗位卡片：左侧品牌色条 + 移动端active反馈

- 卡片左边缘加 `3px solid` 品牌色条（默认 25%透明度，`:active` 变全亮）
- 移动端网格间距从 20px 压缩到 14px
- 卡片 `:active` 缩放 0.98

### 3. 岗位区底部CTA按钮（新增）

- 移动端隐藏右上角"查看全部"文字链接
- 新增底部居中边框样式大按钮 `router-link to="/jobs"`，只在岗位数≥6时显示

### 4. 关于我们：企业精神2×2卡片 + 业务板块横向滑动

- 企业精神4词从 border-pill 横排→2×2 grid 迷你卡片（含品牌色圆点装饰）
- 业务板块3卡片：桌面端垂直堆叠→移动端横向滑动（`scroll-snap` + `75vw` 宽度）
- 文字字号 15px→14px（移动端）

### 5. 全局间距压缩

| 区域 | 桌面端 | 移动端(新) |
|------|--------|-----------|
| Hero | 120px/80px | 64px/48px |
| Section | 80px | 48px |
| Section-header下 | 40px | 24px |

### 6. Section间渐变分隔线

- 替换 `border-top: 1px solid` 为渐变伪元素（两端渐隐品牌色线条）
- 居中，宽度 60-70%

### 7. 中央光晕增强

- `.hero__nebula` 透明度从 0.08 提升到 0.10，大小改为 `min(600px,80vw)`
- 桌面端保留极慢速脉动动画

### 8. 滚动动画微调

- 移动端位移从 24px→16px，时长从 0.8s→0.5s

### 9. 全局移动端触摸反馈

- `global.css` 移动端媒体查询追加 `a:active/button:active` 透明度反馈
- 所有卡片 `:active` 统一缩放 0.98
