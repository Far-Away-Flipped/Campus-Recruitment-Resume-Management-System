## 一、Bug 9：数据报表（ReportView.vue）数据展示修复

### 修复内容

**文件**：`code/recruit-admin-ui/src/views/recruit/report/ReportView.vue`

**问题根因**：前端图表使用了从后端 API 获取数据，但存在参数名和数据字段名映射错误：

| 问题 | 修复前 | 修复后 |
|------|--------|--------|
| 分页参数名不一致 | `page`/`size` | `pageNum`/`pageSize`（与后端 PageQuery 对齐） |
| 报表VO字段映射错误 | `d.count`（4处分布图表） | `d.value`（ReportDataVO 字段名为 value） |

### 修复列表

1. **`fetchStats()` 中 `page`/`size` → `pageNum`/`pageSize`**（4处）
   - `/jobs/list` 查询在招岗位数
   - `/resumes/list` 查询待筛选量（2处：PENDING + PASSED/总量）
2. **`fetchSchoolDistribution()` 中 `d.count` → `d.value`**（学校分布柱状图）
3. **`fetchDegreeDistribution()` 中 `d.count` → `d.value`**（学历分布饼图）
4. **`fetchChannelSource()` 中 `d.count` → `d.value`**（渠道来源饼图）
5. **`fetchJobRanking()` 中 `d.count` → `d.value`**（岗位排行横向条形图）

**注意**：`fetchTrend()` 中的 `d.count` 保持不变，因为 `TrendReportVO` 字段名确为 `count`。

## 二、Bug 13：学生用户管理模块（新建）

### 2.1 后端

**新建文件**：

| 文件 | 说明 |
|------|------|
| `recruit-biz/.../admin/vo/StudentManageVO.java` | 学生列表VO（studentId/phone/realName/email/createTime/status/applyCount） |
| `recruit-biz/.../admin/controller/StudentManageController.java` | 学生管理控制器 |

**StudentMapper.java 新增方法**：
- `selectStudentPage(Page, keyword, status)` — 分页查询学生用户列表，LEFT JOIN stu_profile 获取姓名/邮箱，子查询统计投递数

**API 端点**：
- `GET /api/admin/students/list?pageNum=&pageSize=&keyword=&status=` — 分页查询
- `PUT /api/admin/students/{id}/status?status=ACTIVE|DISABLED` — 启用/禁用
- `DELETE /api/admin/students/{id}` — 逻辑删除（MyBatis-Plus @TableLogic）

### 2.2 前端

**新建文件**：
- `src/views/system/student/StudentList.vue` — Element Plus 表格页面

**修改文件**：
- `src/router/index.js` — 新增路由 `/system/students`
- `src/layout/Sidebar.vue` — 系统管理子菜单添加"学生用户"

**StudentList.vue 功能**：
- 表格列：ID、手机号、姓名、邮箱、注册时间、账号状态（正常/已禁用标签）、投递数
- 搜索：手机号/姓名关键词模糊搜索
- 状态筛选：全部/正常(ACTIVE)/已禁用(DISABLED)
- 操作：启用/禁用切换（确认弹窗）、删除（确认弹窗 + 逻辑删除）
- 分页：支持 10/20/50 条每页
