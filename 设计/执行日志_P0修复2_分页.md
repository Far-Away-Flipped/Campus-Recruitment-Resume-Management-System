# P0修复2：分页失效修复 执行日志

## 修复时间
2026-08-08

## 根因
前端发送 `{page: 2, size: 10}`，后端 `PageQuery` 类接收 `pageNum` 和 `pageSize`。Spring 找不到 `pageNum` 参数，始终用默认值 pageNum=1，导致分页永远显示第1页。

## 修改清单

### 前端（3个Vue文件）

#### 1. ResumeList.vue
- `query` 对象：`page` → `pageNum`，`size` → `pageSize`
- `el-pagination`：`v-model:current-page="query.pageNum"`，`v-model:page-size="query.pageSize"`
- `handleSearch`/`handleReset`：重置使用 `query.pageNum`
- `fetchJobOptions`：API 参数 `pageNum: 1, pageSize: 200`
- `handleExport`：全量拉取参数 `pageNum: 1, pageSize: 10000`

#### 2. SysUserList.vue
- `query` 对象：`page` → `pageNum`，`size` → `pageSize`
- `el-pagination`：`v-model:current-page="query.pageNum"`，`v-model:page-size="query.pageSize"`
- `handleSearch`/`handleReset`：重置使用 `query.pageNum`
- `fetchRoleOptions`：API 参数 `pageNum: 1, pageSize: 100`

#### 3. SysRoleList.vue
- `query` 对象：`page` → `pageNum`，`size` → `pageSize`
- `el-pagination`：`v-model:current-page="query.pageNum"`，`v-model:page-size="query.pageSize"`

### 后端（4个Java文件）

#### 4. SysUserController.java
- `list()` 方法：移除手动 subList 内存截断，改为调用 `userService.selectUserPage(user, pageQuery)` 获取 MyBatis-Plus `IPage` 分页结果
- 清理无用 import：`java.util.List`、`com.baomidou.mybatisplus.extension.plugins.pagination.Page`

#### 5. ISysUserService.java
- 新增方法：`IPage<SysUser> selectUserPage(SysUser user, PageQuery pageQuery)`
- 新增 import：`PageQuery`、`IPage`

#### 6. SysUserServiceImpl.java
- 新增实现：`selectUserPage()` — 构建 MyBatis-Plus `Page` 对象 + `LambdaQueryWrapper`，支持 keyword 多字段模糊匹配（用户名/手机号/昵称）、status 精确查询、deptId 精确查询，按 userId 升序

#### 7. SysRoleController.java
- `list()` 方法：移除手动 subList 内存截断，改为调用 `roleService.selectRolePage(role, pageQuery)` 获取 MyBatis-Plus 分页
- 新增 import：`IPage`（保留 `List` 用于 `all()` 方法）

#### 8. ISysRoleService.java
- 新增方法：`IPage<SysRole> selectRolePage(SysRole role, PageQuery pageQuery)`
- 新增 import：`PageQuery`、`IPage`

#### 9. SysRoleServiceImpl.java
- 新增实现：`selectRolePage()` — 构建 MyBatis-Plus `Page` 对象 + `LambdaQueryWrapper`，支持 roleName/roleKey 模糊查询、status 精确查询，按 roleSort 升序

## 编码模式
- 前端分页：遵循 Element Plus el-pagination 规范，双向绑定 `pageNum`/`pageSize`
- 后端分页：参照 `JobPositionServiceImpl.selectJobList()` 模式 — Service 层构建 `Page<SysXxx>` + `LambdaQueryWrapper`，调用 `mapper.selectPage(page, wrapper)`
- Controller 层：参照 `JobAdminController.list()` 模式 — 调用 Service 分页方法，通过 `TableDataInfo.of(total, records)` 返回

## 验收标准
- [x] 前端 query 对象参数名与后端 PageQuery 字段名一致（`pageNum`/`pageSize`）
- [x] el-pagination 绑定变量名与 query 对象一致
- [x] 后端不再全量查表再 subList，改用 MyBatis-Plus 数据库级分页
- [x] 语法/import 无错误
