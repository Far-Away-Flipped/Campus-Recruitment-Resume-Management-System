> 基准日期：2026-08-10　品牌基线：[官网](http://www.at-moto.com/home) + [品牌视觉规范](_briefs/品牌视觉规范.md)

## 一、现状诊断

### 1.1 核心问题

学生端门户在手机上存在多项可用性障碍，直接影响岗位浏览→投递→资料维护的核心链路转化。

| 问题 | 严重度 | 影响 |
|------|--------|------|
| 表单输入 `font-size:14px` 触发 iOS Safari 缩放 | CRITICAL | 聚焦输入框时页面自动放大且不自动缩回，打断操作流 |
| PortalHeader 4 个导航链接 + 按钮横向排列，375px 完全放不下 | CRITICAL | 学生无法导航到子页面 |
| 筛选栏 5 个自定义下拉 + 2 个按钮水平排列 | CRITICAL | 岗位列表筛选功能在手机上完全不可用（S-011 是 P0 必做） |
| 触摸目标 <28px（当前按钮 `padding:6px 16px`，实际可点击高度约 26px） | HIGH | 拇指反复点不中，宣讲会拥挤环境尤其严重 |
| 卡片网格 `minmax(360px,1fr)` 在 375px 手机上溢出 | HIGH | 手机横屏或有 padding 时首列卡片被裁切 |
| Google Fonts CDN 加载 `Share Tech Mono`（国内不可达） | HIGH | 字体加载失败 → 排版崩塌 |
| 岗位详情页的投递卡片在手机上半屏位置不可达 | MEDIUM | 学生看完全部 JD 后才能滚动到下方点击投递 |
| Hero 星空 CSS 7层 `radial-gradient` + `backdrop-filter:blur` 低端机掉帧 | MEDIUM | 宣讲会现场打开首页卡顿 |

### 1.2 品牌约束

配色/字体/Logo 必须与官网完全一致：

| 元素 | 值 |
|------|-----|
| 主色 | `#5FB8D6` (`var(--color-primary)`) |
| 背景 | `#0A0E17` (`var(--color-bg)`) |
| 卡片 | `#152535` (`var(--color-card)`) |

| 字体 | `--font-sans: 'PingFang SC','Microsoft YaHei'...` / `--font-mono: 'Share Tech Mono'` (自托管) |

## 二、技术方案（经审计修正后的最终方案）

### 2.1 架构约束：Vue Scoped CSS 下的正确定位

**关键发现（审计 CRITICAL O-01）**：Vue `&lt;style scoped&gt;` 的特异性高于全局 CSS，全局类无法覆盖 scoped 样式。因此本方案的核心机制是 **CSS 自定义属性**（`var(--*)` 通过继承传递，不受 scoped 隔离影响），而非传统的全局 CSS 覆盖。

### 2.2 断点体系

| 断点 | 范围 | 变量名 | 用途 |
|------|------|--------|------|
| 小屏手机 | <480px | `--portal-bp-sm` | iPhone SE/老安卓 |
| 中屏手机 | 480-639px | `--portal-bp-md` | iPhone 12/13 |
| 大屏手机 | 640-767px | `--portal-bp-lg` | iPhone 14 Pro Max/小平板竖屏 |
| 平板 | 768-1023px | `--portal-bp-tablet` | iPad/小笔记本 |
| 桌面 | ≥1024px | `--portal-bp-desktop` | 大屏显示器 |

**实用简化**：所有页面统一以 `max-width: 767px` 为主移动断点，480px 和 640px 仅在精细控制的场景使用。

### 2.3 CSS 变量体系（S0 前置，在 `variables.css` 新增）

```css
:root {
  /* ===== 已有品牌变量（不变） ===== */
  --color-primary: #5FB8D6; --color-bg: #0A0E17; --color-card: #152535;
  --color-text: #FFFFFF; --color-text-secondary: #9CA3AF;
  --font-mono: 'Share Tech Mono','Courier New',monospace;
  --font-sans: 'PingFang SC','Microsoft YaHei','Source Han Sans SC',sans-serif;
  --radius: 8px;

  /* ===== 新增：移动端响应式变量 ===== */
  /* 容器 */
  --container-max: 1200px;
  --container-px: 24px;

  /* 触摸友好 */
  --touch-min: 44px;      /* Apple HIG 最小触摸目标 */
  --input-min-h: 48px;    /* 移动端输入最小高度 */

  /* 间距 */
  --spacing-page-x: 16px; /* 页面水平padding(移动端) */
}
```

### 2.4 全局移动端规则（在 `global.css` 追加）

由于 Vue scoped 限制，全局规则只设置**真正全局**的低特异性基础值（body 字号、input 最小尺寸），各页面的容器/布局由各自的 scoped `@media` 处理。

```css
/* 移动端全局基础 */
@media (max-width: 767px) {
  body { font-size: 16px; -webkit-text-size-adjust: 100%; }
  /* 输入框防iOS缩放（全局最小基线，scoped可覆盖增强） */
  input, select, textarea { min-height: var(--input-min-h); }
  /* 按钮最小触摸区域 */
  button, [role="button"], .btn-submit, .btn-ghost, .btn-primary {
    min-height: var(--touch-min); min-width: var(--touch-min);
  }
}
/* 动画降级 */
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important; transition-duration: 0.01ms !important;
  }
}
```

### 2.5 关键页面改造方案

#### PortalHeader — 汉堡菜单 + 右侧抽屉

- 移动端(≤767px)：隐藏桌面导航和按钮区，显示 48×48px 汉堡按钮
- 点击弹出 `Teleport to body` 的右侧滑入抽屉（280px 宽，z-index:200）
- 抽屉含全高度导航链接 + 登录/注册按钮
- 打开时锁定 body 滚动

#### HomeView — 动画降级 + 删除重复页脚

- 移动端：星空 `background-image` 从 7 层降至 3 层 radial-gradient
- `prefers-reduced-motion:reduce` → 完全移除背景动画
- Hero 标题字号 `clamp()` 移动端最小 28px
- **删除内联 `<footer class="footer">`**（与 App.vue 的 PortalFooter 重复）
- 统计区 4 列 → 2×2 网格

#### JobListView — 筛选栏 Bottom Sheet

- 移动端常显搜索框 + 「筛选」按钮（含已选条件计数徽标），点击弹出底部半屏面板
- Bottom Sheet：4 个下拉垂直堆叠 + 底部「重置」+「应用筛选」双按钮

#### 表单五页面 — 触摸友好改造

- 登录/注册/资料/教育经历/投递确认：所有 input `font-size:16px`，提交按钮全宽
- 双列表单格 → 单列
- 弹窗改为底部滑入

#### JobDetailView/ApplyView — 底部固定操作区

- 岗位详情：投递卡片固定在底部（sticky bottom 0），留出 `padding-bottom:80px`
- 投递确认：确认按钮全宽 + 底部固定，留出安全区

## 四、验收标准

1. 手机(375px-428px 宽)上：首页不溢出、星空不卡顿、按钮不小于 44px
2. 岗位列表：筛选栏可正常打开 Bottom Sheet 筛选、岗位卡片全宽不溢出
3. 登录/注册：输入框聚焦不触发 iOS Safari 缩放、提交按钮全宽可靠点击
4. 岗位详情：投递卡片固定在底部可见、点击投递进入确认页
5. 导航：汉堡菜单 → 抽屉正常滑入/滑出、链接可正确跳转
6. `npm run build` 通过，无新增 npm 依赖，gzip 不超过 250KB 基线
