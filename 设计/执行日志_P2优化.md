## Bug 3: 岗位管理列表排序

### 前端

- **目标文件**: `code/recruit-admin-ui/src/views/recruit/job/JobList.vue`
- **改动**:
  1. 为 5 个 `<el-table-column>` 增加 `sortable="custom"` 属性（岗位名称、部门、工作地点、状态、截止日期）
  2. `el-table` 增加 `@sort-change="handleSortChange"` 事件监听
  3. `query` reactive 新增 `sortField` / `sortOrder` 字段
  4. 新增 `handleSortChange({prop, order})` 方法：将 order 转换为 `asc`/`desc` 后更新 query 并重新 fetch
  5. `handleReset` 重置 sortField/sortOrder

### 后端 Controller

- **目标文件**: `code/recruit-backend/recruit-biz/.../admin/controller/JobAdminController.java`
- **改动**: `list()` 方法新增 `@RequestParam(required=false) String sortField` 和 `sortOrder` 参数，注入到 `PageQuery.orderByColumn` / `isAsc`

### 后端 Service 接口

- **目标文件**: `code/recruit-backend/recruit-biz/.../admin/service/JobPositionService.java`
- **改动**: `selectJobList()` 方法签名不变（排序参数走 `PageQuery`），注释更新

### 后端 Service 实现

- **目标文件**: `code/recruit-backend/recruit-biz/.../admin/service/impl/JobPositionServiceImpl.java`
- **改动**:
  1. 新增 `SORT_COLUMN_MAP` 静态映射：title/deptName/location/status/deadline/applicationCount → Lambda 列引用（deptName 非持久字段，映射到 deptId）
  2. `selectJobList()` 方法：读取 `pageQuery.getOrderByColumn()`，查表命中则调用 `wrapper.orderBy(true, isAsc, column)`；默认仍以 createTime DESC 排序
  3. 新增 `SFunction` import，移除无用 `import java.util.Map`

- **状态**: 已完成
