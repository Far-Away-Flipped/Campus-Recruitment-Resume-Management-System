### 1.4 校招系统落地建议

| 场景 | 配色策略 |
|---|---|
| **学生端门户（前台）** | 沿用官网深空风：`#0A0E17` 背景 + `#152535` 卡片 + `#5FB8D6` 主色 + `#6BB3FF` 强调。保持品牌一致性，强化雇主品牌感知 |
| **HR 端后台** | **浅色主题**：表格密集型后台长时间使用，深色底不利于阅读与打印导出。用白底 + `#5FB8D6` 作为主按钮/选中态/链接色，保留品牌识别但优先可用性 |
| **状态语义色** | 通过=`#5FB88D`（官网辅助绿）；淘汰/危险=需新增红色（官网无，建议 `#E05252`）；待处理=`#9CA3AF`；进行中=`#6BB3FF` |

> ⚠️ 官网调色板中**没有警告/错误红色**（纯展示型官网无表单反馈需求）。HR 后台必须新增语义色，建议采用与主色协调的低饱和红 `#E05252` 与橙 `#E8A33D`，并在 A-001 品牌配置中可覆盖。

### 2.2 字间距

- `--letter-spacing-header`: 2px（小屏）/ 4px（大屏）——标题宽字距，科技感来源
- `--letter-spacing-mono`: 0px

### 2.3 校招系统落地建议

| 项 | 结论 |
|---|---|
| **Cinzel / Rajdhani / Share Tech Mono 均为拉丁字体，无中文字形** | 中文会 fallback 到系统字体。官网英文标题用 Cinzel 有效，**中文标题必须另配中文字体** |
| **中文字体方案** | 优先系统字体栈，零加载成本、零版权风险：`"PingFang SC", "Microsoft YaHei", "Hiragino Sans GB", "Source Han Sans SC", sans-serif` |
| **英文/数字** | 学生端可保留 `Rajdhani`（UI）与 `Share Tech Mono`（数据），需自托管字体文件，勿依赖 Google Fonts CDN（国内访问不稳定） |
| **HR 后台** | 全部使用系统字体栈，不加载 Web Font——后台重效率不重氛围，减少一个加载失败点 |
| **字号** | 后台不采用官网的 80px 巨型标题体系，使用组件库默认（14px base） |
