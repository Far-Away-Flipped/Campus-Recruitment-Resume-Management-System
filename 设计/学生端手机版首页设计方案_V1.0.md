# 学生端手机版首页设计方案 V1.0

> **状态**：设计阶段（待评审）
> **设计日期**：2026-08-10
> **适用端**：学生门户（recruit-portal-ui）手机版
> **基准宽度**：375px（iPhone SE），上限 428px（iPhone 14 Pro Max）
> **设计策略**：从零设计，不参考旧版 HomeView.vue（历史遗留横向溢出、间距混乱等问题）

---

## 一、设计原则

| 原则 | 说明 |
|------|------|
| **纯单列** | 所有内容单列纵向排列，禁用 `grid-template-columns` 多列布局，`overflow-x: hidden` 全局强制 |
| **品牌一致** | 沿用官网深空视觉语言（`#0A0E17` 背景 + `#5FB8D6` 主色），与官网跳转时视觉无割裂感 |
| **触摸优先** | 所有可点击元素触摸目标 >= 44px（Apple HIG），按钮全宽 >= 48px 高 |
| **内容克制** | 零装饰性元素（无渐变球、无多余动效），航天科技感来自字体/间距/色彩而非装饰 |
| **性能优先** | 零 Web Font 加载（中文走系统字体栈），零 JS 动效库（CSS transition 足够），首屏 < 50KB（gzip） |
| **渐进增强** | 基准 375px 完美呈现，428px 等比放大字号/间距（使用 `clamp()` 流体值） |

## 四、逐区块详细设计

### 4.1 Hero 区

**高度策略**：约 60-70vh（`min-height: 65vh`），不占满全屏——让用户能看到下方内容暗示，鼓励滚动。

#### 4.1.1 背景层

| 属性 | 值 | 说明 |
|------|-----|------|
| 底色 | `#0A0E17`（`--color-bg`） | 深空黑蓝 |
| 星点层 | 纯 CSS `box-shadow` 或 `radial-gradient` 生成 30-50 个随机星点 | 无 JS 无图片，性能最优 |
| 底部渐变遮罩 | `linear-gradient(to bottom, transparent 70%, var(--color-bg) 100%)` | 自然过渡到下一 section |
| 星点颜色 | `rgba(255,255,255,0.6)` 到 `rgba(255,255,255,0.2)` | 大小 1-2px，模拟星空 |

#### 4.1.2 内容层元素

**元素 1：企业全称**
- 文字：`遨天科技（北京）有限公司`
- 来源：品牌视觉规范 5.4 节，官网 meta description
- 样式：`font-size: 12px; color: #6E7D8A; text-align: center; letter-spacing: 2px;`

**元素 2：企业精神 tagline**
- 文字：`团结、务实、厚德、尚道`
- 来源：官网 HTML 第 62 行（企业精神原文）；品牌视觉规范 5.1 节
- 样式：`font-size: 13px; color: #FFFFFF; text-align: center; letter-spacing: 6px; font-weight: 500;`
- 分隔符使用中文顿号 `、`（与官网一致）

**元素 3：主标题**
- 文字第一行：`赋能人类`
- 文字第二行：`太空活动`
- 来源：官网 slogan；品牌视觉规范 5.2 节
- 样式：`font-size: 32px; font-weight: 700; color: #FFFFFF; text-align: center; letter-spacing: 4px; line-height: 1.2;`
- 两行之间间距 `4px`，不使用 `<br>`——用两个 `<span>` 分行更可控

**元素 4：描述文字**
- 文字：`构建连接太空的基础设施，以电推进动力与全域态势感知技术，重新定义空间探索的边界。`
- 来源：官网 HTML 第 62 行；品牌视觉规范 5.2 节
- 样式：`font-size: 14px; color: #9CA3AF（--color-text-secondary）; text-align: center; line-height: 1.7;`
- 在 343px 内容宽度下约 3 行，每行约 22 中文字符（14px*22=308px，容得下）

**元素 5：公司定位**
- 文字：`国家级专精特新"小巨人"企业`
- 来源：官网 HTML 第 10 行 meta description；品牌视觉规范 5.4 节
- 样式：`font-size: 12px; color: #5FB8D6（--color-primary）; text-align: center; letter-spacing: 2px; font-weight: 500;`

**元素 6：CTA 按钮**
- 文字：`查看在招岗位 →`
- 样式：
  ```
  display: block; width: 100%; height: 48px;
  background: linear-gradient(135deg, #5FB8D6, #6BB3FF);
  color: #0A0E17; font-size: 15px; font-weight: 600;
  border: none; border-radius: 8px（--radius）;
  letter-spacing: 2px; text-align: center;
  line-height: 48px; text-decoration: none;
  ```
- 交互：`active` 态 `transform: scale(0.97)`，`transition: transform 0.1s ease`
- 路由：`/jobs`（与旧版一致）
- 触摸目标：48px 高 >= 44px Apple HIG

#### 4.3.2 岗位卡片设计

**数据来源**：动态数据，来自 `/api/portal/jobs` 接口（现有接口）。
**展示数量**：最多 3 张卡片（手机端首屏不做分页，剩余引导到 `/jobs` 列表页）。

**卡片结构**：

```
┌──────────────────────────────────────────────┐
│                                              │
│  电源研发工程师                               │  ← 岗位名
│                                              │
│  [研发部] [北京] [硕士] [2026-09-30]          │  ← 标签行：部门/地点/学历/截止日期
│                                              │
└──────────────────────────────────────────────┘
```

**卡片 CSS 参数**：

| 属性 | 值 |
|------|-----|
| 宽度 | `100%`（343px 可用内容区） |
| 背景 | `#152535`（`--color-card`） |
| 圆角 | `8px`（`--radius`） |
| 内边距 | `16px` |
| 底边框 | `1px solid rgba(95, 184, 214, 0.08)` |
| 岗位名字号 | `16px`，`font-weight: 600`，`color: #FFFFFF` |
| 标签 pill | `font-size: 11px`，`padding: 2px 8px`，`border-radius: 4px`，`background: rgba(95,184,214,0.1)`，`color: #9CA3AF` |
| 卡片间距 | `12px`（`gap` 或 `margin-bottom`） |
| 交互 | `active` 态 `transform: scale(0.98)` + 背景微调 `#1A3045` |

## 五、全局动效规范

### 5.1 入场动画

仅 Hero 区使用极简入场动画（`@vueuse/motion` 或纯 CSS animation），以下区域除外不做入场动效：

| 元素 | 动画 | 时长 | 延迟 | 缓动 |
|------|------|------|------|------|
| 企业全称 | `fadeInUp` | 0.6s | 0s | `ease-out` |
| 企业精神 | `fadeInUp` | 0.6s | 0.1s | `ease-out` |
| 主标题第一行 | `fadeInUp` | 0.6s | 0.2s | `ease-out` |
| 主标题第二行 | `fadeInUp` | 0.6s | 0.25s | `ease-out` |
| 描述文字 | `fadeInUp` | 0.6s | 0.3s | `ease-out` |
| 公司定位 | `fadeInUp` | 0.6s | 0.35s | `ease-out` |
| CTA 按钮 | `fadeInUp` | 0.6s | 0.4s | `ease-out` |

数据背书区、岗位区、关于区**不做入场动画**——用户已经滚动到该区域时内容应立即可见，避免"等动画"的挫败感。

### 5.2 交互动效

| 交互 | 动效 | 时长 |
|------|------|------|
| 卡片/按钮 `active` | `transform: scale(0.97-0.98)` | 0.1s |
| 链接 hover（如有） | `opacity: 0.8` | 0.15s |
| 业务卡片滑动 | 原生惯性滚动（`-webkit-overflow-scrolling: touch`） | N/A |

### 5.3 动效降级

```css
@media (prefers-reduced-motion: reduce) {
  .hero__content > * {
    animation: none !important; opacity: 1 !important;
  }
}
```
已与 `global.css` 中全局 `prefers-reduced-motion` 规则叠加生效。

## 九、响应式边界处理

### 9.1 宽度断点策略

本设计面向 375px-428px 移动端。使用 `clamp()` 实现流体字号，避免在两个宽度下差异过大：

```css
/* 示例：主标题在 375px 下 32px，428px 下 36px */
.hero__title-line {
  font-size: clamp(32px, 8.53vw, 36px);
}
/* 描述文字 */
.hero__desc {
  font-size: clamp(14px, 3.73vw, 15px);
}
```

### 9.2 428px 下的调整

| 元素 | 375px 值 | 428px 值 |
|------|----------|----------|
| 主标题 | `32px` | `36px` |
| 描述文字 | `14px` | `15px` |
| 数据数值 | `28px` | `32px` |
| CTA 按钮高 | `48px` | `52px` |
| 业务卡片宽 | `281px (75vw)` | `300px（max-width 限制）` |

### 9.3 平板及以上（>= 768px）

本设计仅覆盖移动端。平板和桌面端使用旧版 HomeView 或后续独立的桌面版设计。在 `@media (min-width: 768px)` 下，手机版 HomeView 应**不渲染**或由路由层分流。

## 十二、实现注意事项

1. **与现有路由兼容**：手机版 HomeView 可复用同一路由 `/`，通过 `@media` 或 JS 检测屏幕宽度切换渲染不同模板；或单独路由 `/m`。
2. **与 PortalHeader 配合**：页面顶部 56px 留给 Header 组件（`--header-h`），Hero 区 `padding-top: 56px`。
3. **接口数据**：岗位卡片数据来自现有 `/api/portal/jobs`（permitAll），无需新增后端接口。
4. **字体加载**：Share Tech Mono 如已自托管则可继续使用；如未自托管则 fallback 到 Courier New（数据数值失去科技感但功能无损）。
5. **安全区域**：底部 CTA 和交互元素需考虑 iPhone 底部安全区（`env(safe-area-inset-bottom)`），避免被 Home Indicator 遮挡——但 Hero 区 CTA 在页面顶部，不受影响。
6. **测试宽度**：必须实测 375px（iPhone SE）、390px（iPhone 14）、428px（iPhone 14 Pro Max）三个宽度，严禁横向溢出。
7. **暗色模式**：本项目固定深色主题，不做亮色切换。
