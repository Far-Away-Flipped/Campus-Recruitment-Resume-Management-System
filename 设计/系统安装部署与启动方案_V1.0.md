# 系统安装部署与一键启动方案 V1.0

> 编制日期：2026-08-10　基于：实际工具链检测（MySQL 8.0.41 `D:/program/MySQL/` / Java 17 Temurin / Node.js v25.2.1 / Maven 3.9.16 本地） + 系统架构设计

---

## 一、方案概述

两个方案覆盖系统全生命周期：

| 方案 | 频率 | 目标 |
|------|------|------|
| **系统安装部署** | 一次性（新机器/重装系统时） | 从零搭建可运行环境 |
| **系统一键启动** | 日常（每次开机/需要时） | 一键拉起全部服务 |

## 三、方案一：系统安装部署

### 3.1 部署流程（六个阶段）

```
阶段1: 环境检测
  ├── Java 17+ / Node.js 18+ / MySQL / Maven 本地路径
  ├── 端口 3306/8080/5173/5174 冲突检测
  └── LibreOffice（可选，缺失仅警告）

阶段2: 数据库初始化 [幂等]
  ├── 启动 MySQL（如未运行）
  ├── 检测 atmoto_recruit 库 → 不存在则建库+执行 init-schema.sql + init-data.sql
  └── 已存在且有表 → 跳过

阶段3: 后端构建
  ├── Maven 离线打包 (mvn -o package -DskipTests)
  └── 验证 recruit-admin.jar > 30MB

阶段4: 前端构建 [仅生产环境]
  ├── npm install + npm run build（HR端+学生端）
  └── 复制 dist/ 到 E:/atmoto-recruit/web/dist/

阶段5: 目录创建
  └── E:/atmoto-recruit/data/attachments/ + temp/

阶段6: 完成报告
  └── 访问地址、日志路径、下一步提示
```

### 3.2 部署脚本：`系统部署.bat` + `系统部署.ps1`

- **`系统部署.bat`**：纯 ASCII，参数解析，调用 `系统部署.ps1`
- **`系统部署.ps1`**：UTF-8 with BOM，中文输出，六阶段逻辑

**调用方式**：
```
系统部署.bat          # 开发环境（默认）
系统部署.bat dev      # 同上
系统部署.bat prod     # 生产环境（含前端构建）
```

**幂等性**：数据库已存在且有表 → 跳过初始化；Maven/npm 可重复执行。

## 四、方案二：系统一键启动（日常开发）

### 4.1 启动流程（五个步骤）

```
[1/5] 启动 MySQL
  ├── 端口 3306 已监听 → 跳过
  └── 未监听 → Start-Process mysqld.exe，轮询等待（30秒超时）

[2/5] 启动后端
  ├── 端口 8080 已监听 → 跳过
  └── java -jar --spring.profiles.active=dev，轮询 /actuator/health（60秒超时）

[3/5] 启动 HR 前端 (5174)
[4/5] 启动学生前端 (5173)
[5/5] 完成报告（访问地址 + 日志路径）
```

### 4.2 停止流程（四个步骤）

```
[1/4] 停止学生前端 ─→ 读 .runtime/portal-ui.pid → taskkill
[2/4] 停止 HR 前端   ─→ 读 .runtime/admin-ui.pid → taskkill
[3/4] 停止后端       ─→ 读 .runtime/backend.pid → 优雅停止（5秒）→ 强制
[4/4] 停止 MySQL     ─→ 读 .runtime/mysql.pid → taskkill（可选 --keep-mysql）
```

**进程识别**：通过 PID 文件精确停止（不误杀同名进程）。

### 4.3 启动脚本：`系统一键启动.bat` + `系统一键启动.ps1`

**调用方式**：
```
系统一键启动.bat              # 开发环境（默认）
系统一键启动.bat dev --open   # 启动后自动打开浏览器
系统一键启动.bat prod         # 生产环境（不使用 Vite dev server）
```

### 4.4 停止脚本：`系统停止.bat` + `系统停止.ps1`

**调用方式**：
```
系统停止.bat               # 停止全部服务
系统停止.bat --keep-mysql  # 保留 MySQL
系统停止.bat --force       # 跳过优雅停止，直接 kill
```

## 六、错误处理速查

| 场景 | 处理 |
|------|------|
| Java < 17 或未安装 | 输出 https://adoptium.net/download/，中止 |
| Node.js < 18 或未安装 | 输出 https://nodejs.org/，中止 |
| MySQL 未找到 | 输出安装提示，中止 |
| 端口被占用 | 输出 `netstat -ano` 占用信息，中止 |
| MySQL 启动超时 (>30s) | 提示检查 `D:/program/MySQL/data/*.err`，中止 |
| Maven 编译失败 | 输出错误日志最后 20 行，中止 |
| npm install 失败 | 提示设置镜像 `npm config set registry https://registry.npmmirror.com` |
| 后端启动超时 (>60s) | 提示检查 `logs/` 目录，中止 |
| JAR 文件不存在 | 提示先执行 系统部署.bat |

## 七、与现有代码的关系

- **零侵入**：不修改任何现有代码、配置文件、SQL 脚本
- **Maven**：使用项目自带的 `下载/apache-maven-3.9.16/bin/mvn`，不要求 PATH
- **MySQL 路径**：`D:/program/MySQL/bin/`（本机实际安装位置，新机器需修改脚本顶部常量）
- **已有 bug 不修复**：`backup.ps1` 中 `C:\Program Files\MySQL\...` 与实际 `D:/program/MySQL/` 不一致，不在本方案范围
